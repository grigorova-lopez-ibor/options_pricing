\section*{In-sample, out-of-sample and hybrid labels}
Every label needs an early-exercise rule, estimated by least-squares Monte Carlo (LSM) backward
regression. The three versions differ only in \emph{which paths the rule is fitted on}:
\begin{itemize}\itemsep1pt
\item \textbf{Out-of-sample (OOS):} the rule is fitted on the 100,000 pilot paths and applied to the
300,000 independent main paths. Because the rule never sees the main paths, it is slightly
suboptimal on them, so the price is a low-biased estimate; the bias depends on the pilot, not on
the number of main paths.
\item \textbf{In-sample (IS):} the rule is fitted on the 300,000 main paths and applied to the same
paths (as in the paper's method). The rule can exploit the particular paths (foresight), so the
price is high-biased; this bias shrinks roughly like $1/N$ in the number of main paths.
\item \textbf{Hybrid (Hyb):} the average of the OOS and IS estimates for Price, Delta, Gamma, Theta,
Charm, Vega, Rho and Phi, and the OOS estimate for Volga, Vanna, $\partial_r\Delta$ and
$\partial_d\Delta$. Both versions come from the same simulation.
\end{itemize}

\section*{Method and evaluation scope}
American puts are approximated with 504 Bermudan exercise opportunities per year (two per business day).
For each target $(S_0,K,\sigma,r,d,T)$, a \textbf{100,000-path pilot} selects the widths over which
initial stock prices and volatilities are dispersed. \textbf{300,000 new main paths} are then simulated
from those dispersed initial states $(S_0^{(i)},\sigma^{(i)})$. With the exercise rule (IS or OOS, as
above) each path $i$ has an exercise time $\tau_i$ (an exercise date or $T$) and
a discounted payoff $Y_i=e^{-r\tau_i}(K-S_{\tau_i})^+$. Regressing $Y_i$ on a polynomial in
$(S_0^{(i)}-S_0,\ \sigma^{(i)}-\sigma)$ gives the price as the value of the fitted polynomial at
$(S_0,\sigma)$, and Delta, Gamma, Vega, Volga and Vanna as its derivatives there.

\textbf{Pathwise derivatives (Rho, Phi, Theta).} The rate, dividend and maturity
are not dispersed at the starting point, for each label we compute they are fixed. Rho and Phi are computed as \textbf{pathwise derivatives}: each path's discounted
payoff is differentiated analytically in $r$ and $d$ with its exercise time $\tau_i$ held fixed. Theta is computed
the same way in $T$, with every exercise date a fixed fraction of $T$.
The per-path derivatives are regressed on the same polynomial in the dispersed initial states: the
value at $(S_0,\sigma)$ gives Rho, dividend Phi and Theta $=-\partial P/\partial T$, and the slope in
$S$ gives the cross-rate Deltas $\partial_r\Delta$, $\partial_d\Delta$ and Charm.

All tests compare against a finite-difference \textbf{continuous-American PDE reference}, not an
assumed exact ground truth.

Timings are on one CPU. The out-of-sample label is produced in the hybrid run; its cost alone was not
measured separately.

\textbf{Cost of additional paths.} Computation time grows linearly with the number of main paths and
with the number of exercise dates ($504\,T$). For the in-sample label, each additional 100,000 main
paths adds about \textbf{19\,s} per label at $T=1$ and about 37\,s at $T=2$, i.e.\ roughly
$0.2$\,ms per path at $T=1$, or about $0.4\,\mu$s per path and exercise date. Starting from the
default of 300,000 paths ($\sim$55\,s at $T=1$), 100,000 more paths therefore make a label about
35\% more expensive, and doubling to 600,000 paths roughly doubles its cost. The hybrid label, which
fits both the in-sample and the out-of-sample rule, adds about 29\,s per 100,000 paths at $T=1$.
Time is close to linear in the number of main paths (with a small fixed cost for the pilot): in the
path study the extra time per 100,000 paths rose only from about 12\,s to 16\,s between 75k and
600k paths, and doubling from 300k to 600k paths took 2.08 times as long.
In comparison, an additional label costs the full per-label time ($\sim$70\,s on average for the
in-sample label). Additional labels reduce noise like $n^{-1/2}$ but leave the bias unchanged;
additional paths reduce the noise of each label like $N^{-1/2}$.
